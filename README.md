# Abdulrahman Suddy — personal website

Single-page site for Abdulrahman Suddy (business & financial advisory), hosted with GitHub Pages.

- `index.html` is the whole site: HTML, CSS, JS and photos in one file.
- Brand: orange `#EA6134`, navy `#32344C`, amber `#F8A420`; Poppins, Nunito Sans and Caveat.

## Placeholders still to fill in

Search `index.html` for these and replace them:

| Placeholder | Where | What to put |
|---|---|---|
| `[YOUR_EMAIL_FORM_ENDPOINT]` | popup and newsletter forms (`action=`) | your email provider's form URL |
| `[GOOGLE_CALENDAR_BOOKING_URL]` | "Book an appointment" button | Google Calendar appointment page link |
| booking iframe comment | `#book` section | the Google Calendar embed iframe |
| `[Date]`, `[X] min read`, article titles | `#blog` | your real articles |
| "Coming soon" resource cards | `#resources` | direct file links |

## Publishing changes

Push to `main`; GitHub Pages redeploys in about a minute.
